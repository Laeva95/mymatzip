## 3. 내가 겪은 문제
### ① 공공데이터 중복 저장
- 문제: 공공데이터 일괄 등록 시 주소 표기만 다른 같은 가게가 다른 가게로 저장될 뻔함
- 원인: 이름·주소 글자가 완전히 같을 때만 중복으로 판단함
- 해결: 공백·괄호·층·호·건물명을 뺀 비교용 키 `compareKey()` 추가 → 최종 655곳 중복 없이 등록

### ② 맛집 목록 N+1
- 문제: 맛집 목록 조회 시 맛집마다 평균 별점 쿼리가 추가 실행됨 (N+1)
- 원인: 맛집 1개용 `toResponse()`를 반복 호출해 호출마다 평균 별점 쿼리가 실행됨
- 해결: `IN + GROUP BY` 쿼리 1번으로 평균 별점을 일괄 조회 → 목록 쿼리 14회 → 3회
