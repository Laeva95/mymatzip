# 서희정· 역할: (A 코스)

## 1. 내가 맡은 일 (3~5문장)
회원가입, 로그인, 마이페이지 등 회원·인증 전반의 기능 개발과 보안 개선을 담당했습니다.
Gmail SMTP를 연동해 회원가입 및 로그인 시 6자리 이메일 인증 기능을 새롭게 구현하고, 관리자(ADMIN) 계정은 이메일 인증 없이
로그인할 수 있도록 예외 처리를 적용했습니다. 마이페이지에서는 회원 탈퇴 기능을 추가하고, 비밀번호 변경 시 현재 비밀번호와
동일한 값으로의 변경을 차단하는 이중 검증과 새 비밀번호 확인 입력란을 구현했습니다.
또한 신규 배포 도메인 환경에 맞춰 Google Cloud Console에 Oauth 2.0 승인된 리디렉션 URI를 등록했습니다.
## 2. 내가 직접 만든 파일
- EmailAuthService.java
- EmailAuthApiController.java

## 3. 내가 겪은 문제
- 문제: 로그인 2단계 이메일 인증 적용 후 관리자 계정 로그인 시 버튼 비활성화 및 '이메일 인증을 먼저 완료해주세요.' 문구로 로그인이 차단됨
- 원인: MemberApiController와 login.html에서 회원 권한(Role)을 구분하지 않고 모든 계정에 이메일 인증을 필수로 적용함
- 해결: MemberApiController.login()에 관리자 예외 조건을 추가하고, login.html의 로그인 버튼 기본 비활성화를 해체함
