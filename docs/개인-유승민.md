# 유승민 · 역할: 부팀장

## 1. 내가 맡은 일 (3~5문장)
- 인프라 구축: AWS EC2, RDS(MySQL), S3 및 IAM 환경 설정
- CI/CD 관리: GitHub Actions 기반 Gradle 빌드·테스트 자동화 설정
- 서버 배포: Ubuntu에서 Spring Boot 배포 및 서비스 관리
- 웹 서버 설정: Nginx 리버스 프록시, HTTPS 및 도메인 연결 설정

## 2. 내가 직접 만든 파일
- `.github/workflows/ci.yml`
- `application.properties` (프록시 헤더 처리 설정 수정)
- `../README.md` (프로젝트 소개 및 팀원 역할 정리)

## 3. 내가 겪은 문제
- 문제: 배포 서버에서 Google 로그인 시 `redirect_uri_mismatch` 오류 발생
- 원인: HTTPS 접속 환경에서 Spring Boot가 HTTP 리디렉션 주소를 생성함
- 해결: Nginx의 `X-Forwarded-*` 헤더 설정을 확인하고 `server.forward-headers-strategy=framework` 추가 후 재배포
