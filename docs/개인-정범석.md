# 정범석 · 역할: (C 코스)

## 1. 내가 맡은 일 (3~5문장)
맛집탐방 프로젝트에서 리뷰·별점 기능과 AI 리뷰 요약을 맡았다. 
회원이 맛집에 리뷰와 1~5점 별점을 쓰고 삭제하고 신고할 수 있는 REST API를
Controller → Service → Repository 구조로 만들었다. 리뷰에 답글을 
다는 기능도 구현하고 재현하는 테스트 코드를 작성했다.
## 2. 주요 구현 파일 목록

### ① 엔티티 (Entity)
* `entity/Review.java`: 리뷰 내용(`content`), 별점(`rating`), 작성자(`member`), 대상 맛집(`restaurant`), 이미지 경로(`imageUrl`), 신고 여부(`reported`) 매핑
* `entity/Reply.java`: 리뷰에 종속되는 대댓글 내용(`content`), 작성자(`member`), 대상 리뷰(`review`) 매핑

### ② 리포지토리 (Repository)
* `repository/ReviewRepository.java`: 맛집별 최신순 조회, 평균 별점 계산(`@Query` AVG), 페이징 조회, 신고된 리뷰 조회
* `repository/ReplyRepository.java`: 특정 리뷰의 대댓글 오래된 순 조회(`@EntityGraph` 적용), 회원별 작성 대댓글 조회

### ③ DTO (Data Transfer Object)
* `dto/ReviewForm.java` / `dto/ReviewResponse.java`: 리뷰 입력값 유효성 검증(`@NotBlank`, `@Min(1)`, `@Max(5)`, `@Size(max=1000)`) 및 응답 데이터 변환
* `dto/ReplyForm.java` / `dto/ReplyResponse.java`: 대댓글 입력값 유효성 검증(`@NotNull`, `@NotBlank`, `@Size(max=500)`) 및 응답 데이터 변환

### ④ 서비스 & 컨트롤러 (Service & Controller)
* `service/ReviewService.java`: 리뷰 목록 조회, 작성, 본인 확인 후 삭제, 평균 별점 반올림 처리, 리뷰 신고 처리
* `service/ReplyService.java`: 대댓글 목록 조회, 작성, 본인 확인 후 삭제 처리
* `controller/api/ReviewApiController.java` / `ReplyApiController.java`: 리뷰 및 대댓글 REST API 엔드포인트 제공

## 3. 내가 겪은 문제
- 문제: 없는 ID를 삭제해도 403이 나간다.
  원인: 모든 IllegalArgumentException을 403으로 일괄 처리했다.
  개선 방향: 없음은 404, 권한 없음은 403으로 나눈다.
