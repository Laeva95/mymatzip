# 정범석 · 역할: (C 코스)

## 1. 내가 맡은 일 (3~5문장)
맛집탐방 프로젝트에서 리뷰·별점 기능과 AI 리뷰 요약을 맡았다. 
회원이 맛집에 리뷰와 1~5점 별점을 쓰고 삭제하고 신고할 수 있는 REST API를
Controller → Service → Repository 구조로 만들었다. 리뷰에 답글을 
다는 기능도 구현했다. 리뷰가 3개 이상인 맛집은 Spring AI로 리뷰를 요약해
보여 주는 기능을 만들었다. 구현 뒤에는 내 코드를 직접 검증해 결함 7건을 
찾아 AI 코드 검증일지에 정리하고, 그중 4~7번을 재현하는 테스트 코드를 작성했다.
## 2. 내가 직접 만든 파일
-  entity/Review.java: 리뷰 엔티티 (내용, 별점, 신고 여부)
-   repository/ReviewRepository.java: 맛집별·회원별·신고된 리뷰 조회, 평균 별점 쿼리
-   dto/ReviewForm.java, dto/ReviewResponse.java: 리뷰 작성 요청·응답 DTO (입력값 검증 포함)
-   service/ReviewService.java: 리뷰 등록·삭제·신고, 평균 별점 계산
-   controller/api/ReviewApiController.java: 리뷰 REST API
-   service/ai/AiReviewSummaryService.java: 리뷰 3개 이상일 때 AI 요약 생성
-   entity/Reply.java, repository/ReplyRepository.java: 답글 엔티티와 조회
-   dto/ReplyForm.java, dto/ReplyResponse.java: 답글 요청·응답 DTO
-   service/ReplyService.java, controller/api/ReplyApiController.java: 답글 등록·삭제 (본인만 삭제 가능)
-   test/.../review/ReviewDefectTest.java: 결함 4~7번 재현 테스트
