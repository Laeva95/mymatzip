## 3. 내가 겪은 문제
- 문제: 메인 화면 home.html의 최근 등록된 맛집 6개를 조회할 때 쿼리 N + 1 문제가 발생함
- 원인: 모든 맛집 요소가 리뷰 평점을 계산하기 위해 각자 DB를 조회함
- 해결: 쿼리 한번으로 맛집의 리뷰 평점을 모두 가져와서 하나씩 출력
- 쿼리 수 7회 -> 2회(이후 기능 추가하여 3회)
- 지연 시간 9.35ms → 7.51ms
