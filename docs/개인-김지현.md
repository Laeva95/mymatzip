## 3. 내가 겪은 문제
- 문제: OpenRouter API를 연동하는 과정에서 API 키와 모델 설정이 필요했고, 무료 모델 사용량 제한 및 API 호출 실패에 대한 처리가 필요했다.
- 원인: 외부 AI 서비스는 API 키 인증이 필요하며, 무료 모델도 사용량 제한이 있고 모델에 따라 요청이 실패할 수 있기 때문이다.
- 해결: IntelliJ 실행 환경변수에 API 키와 모델 이름을 설정하고, 무료 모델만 허용하는 FreeModelGuard와 AI 사용 횟수를 관리하는 AiUsageLimiter를 구현했다. 또한 AI 서비스 이용이 불가능한 경우 예외 처리를 추가했다.
